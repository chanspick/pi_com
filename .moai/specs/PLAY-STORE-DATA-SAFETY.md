## 2. 수집하는 데이터 유형

### 2.1 개인정보 (필수)
| 데이터 유형 | 수집 목적 | 공유 여부 |
|------------|----------|----------|
| 이름 | 주문/배송, 계정 관리 | 판매자에게 공유 |
| 이메일 | 계정 인증, 주문 확인 | 결제 대행사에 공유 |
| 전화번호 | 배송 연락, 고객 문의 | 판매자에게 공유 |
| 주소 | 배송지 | 판매자에게 공유 |

| 데이터 유형 | 수집 목적 | 공유 여부 |
|------------|----------|----------|
| 거래 내역 | 주문 관리, 환불 처리 | 결제 대행사에 공유 |
| 결제 수단 | 결제 처리 | 결제 대행사에 공유 |

### 2.3 기기/앱 정보
| 데이터 유형 | 수집 목적 | 공유 여부 |

| 기기 식별자 | 푸시 알림 (FCM) | Google에 공유 |
| 앱 로그 | 오류 분석 | 공유 안함 |

## 4. 데이터 보안

- **전송 중 암호화**: HTTPS/TLS 1.2+
- **저장 시 암호화**: Firebase Firestore 기본 암호화
- **액세스 제어**: Firebase Security Rules 적용

---

## 5. 사용자 권리

### 5.1 데이터 삭제 요청
- **앱 내 삭제**: 설정 > 계정 삭제
- **경로**: `/settings/account-delete`
- **즉시 삭제**: 프로필, 장바구니, 즐겨찾기, 주소
- **법적 보존 (5년)**: 결제 기록, 주문 내역

### 5.2 데이터 내보내기
- 현재 미지원 (향후 구현 예정)
