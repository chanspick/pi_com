1. 청약철회 및 환불 기준

PiCom은 전자상거래법에 따라 다음과 같은 환불 정책을 운영합니다.

1.1 청약철회 가능 기간

구매자는 상품을 공급받은 날(배송 완료일)로부터 7일 이내에 청약을 철회할 수 있습니다. 단, 다음의 경우에는 청약철회가 제한될 수 있습니다:

  • 구매자의 책임 있는 사유로 상품이 훼손된 경우
  • 구매자의 사용 또는 일부 소비로 상품의 가치가 현저히 감소한 경우
  • 시간 경과로 재판매가 곤란할 정도로 상품 가치가 현저히 감소한 경우
  • 복제가 가능한 상품의 포장을 훼손한 경우

1.2 청약철회 불가 사유

⚠️ 다음의 경우 청약철회가 불가능합니다:
  • 부품을 개봉하여 장착/사용한 경우
  • 부품의 시리얼 넘버나 보증 스티커가 훼손된 경우
  • 부품에 물리적 손상(긁힘, 파손 등)이 발생한 경우
  • 부품의 포장이 훼손되어 재판매가 불가능한 경우
  • 구매자의 단순 변심으로 인한 경우

2. 환불 프로세스

2.1 환불 신청 방법

  1. 마이페이지 > 구매내역에서 해당 주문 선택
  2. '환불 신청' 버튼 클릭
  3. 환불 사유 및 상세 내용 작성
  4. 상품 사진 첨부 (필수)
  5. 환불 신청 제출

2.2 환불 처리 절차

단계 내용 소요 기간
1. 환불 신청 구매자가 환불 신청 제출 즉시
2. 검토 판매자 및 PiCom 환불 사유 검토 1-2 영업일
3. 상품 반송 구매자가 상품을 판매자에게 반송 2-3 영업일
4. 상품 확인 판매자가 반송 상품 상태 확인 1-2 영업일
5. 환불 승인 환불 승인 및 결제 취소 처리 즉시
6. 환불 완료 결제 수단별 환불 완료 3-7 영업일

3. 배송비 부담

3.1 판매자 귀책 사유

다음의 경우 왕복 배송비는 판매자가 부담합니다:

  • 상품이 표시·광고 내용과 다른 경우
  • 상품에 하자가 있는 경우
  • 배송 중 파손된 경우

3.2 구매자 귀책 사유

다음의 경우 왕복 배송비는 구매자가 부담합니다:

  • 단순 변심에 의한 반품
  • 구매자의 잘못된 주문

4. 환불 방법

4.1 카카오페이 결제

카카오페이 결제 취소 처리 후 3-5 영업일 내 환불 완료

4.2 계좌이체

구매자가 지정한 계좌로 1-3 영업일 내 환불 완료

5. 부분 환불

여러 상품을 주문한 경우, 일부 상품만 환불을 원하시는 경우:

  • 각 상품별로 개별 환불 신청 가능
  • 환불 상품의 금액만큼만 환불 처리
  • 배송비는 환불 사유에 따라 차등 부담

6. 특수 상황 환불 정책

6.1 품절/재고 부족

판매자가 상품을 배송할 수 없는 경우:

  • 즉시 구매자에게 통지
  • 결제 금액 전액 환불
  • 환불 처리 기간: 3 영업일 이내

6.2 배송 지연

예정된 배송 기한을 초과하는 경우:

  • 구매자는 즉시 주문을 취소하고 전액 환불 요청 가능
  • 배송비 전액 판매자 부담

6.3 판매자 계정 정지

판매자 계정이 정지되어 거래가 불가능한 경우:

  • PiCom이 직접 환불 처리
  • 결제 금액 전액 환불
  • 환불 처리 기간: 7 영업일 이내

7. 중고 부품 특별 유의사항

⚠️ 중고 부품의 특성상 다음 사항에 유의하세요:
  • 사용 흔적(미세한 긁힘, 먼지 등)은 정상적인 중고 상품의 특성으로 환불 사유가 되지 않습니다
  • 상품 설명에 명시된 하자는 환불 사유가 되지 않습니다
  • 호환성 문제는 구매 전 반드시 확인하셔야 하며, 미확인으로 인한 문제는 환불 사유가 되지 않습니다
  • 부품 장착 후 발생한 시스템 문제는 환불 사유가 되지 않습니다

8. 환불 거부 시 이의 제기

환불이 거부된 경우, 다음과 같이 이의를 제기할 수 있습니다:

  1. 마이페이지 > 1:1 문의를 통해 이의 제기
  2. 고객센터 이메일(contact@picom.team)로 상세 내용 전송
  3. PiCom 운영팀이 재검토 (2-3 영업일)
  4. 재검토 결과 통보 및 최종 처리

9. 분쟁 해결

환불 관련 분쟁이 발생한 경우:

  • 1차: PiCom 고객센터를 통한 중재
  • 2차: 한국소비자원 또는 공정거래위원회를 통한 분쟁 조정
  • 3차: 법적 소송 절차
