# 🚀 추천시스템 부족한점
1️⃣ UX/UI 문제점

  - ❌ 게임 번호(1~154) 입력 방식이 불편함
    - 게임 목록을 볼 수 없어서 번호를 외워야 함
    - 검색 기능 없음
  - ❌ 답변 수정 불편
    - 뒤로가기만 가능, 특정 질문으로 바로 이동 불가
  - ❌ 질문 미리보기 없음
    - 총 몇 개 질문인지, 어떤 질문들이 있는지 사전에 알 수 없음

  2️⃣ 추천 알고리즘 한계

  - ❌ 정적인 견적 데이터 (243줄, 하드코딩된 JSON)
    - 견적 샘플이 부족함 (10~20개 정도로 추정)
    - 새로운 부품 출시 시 수동 업데이트 필요
  - ❌ 단순한 매칭 방식
    - 점수 기반 단순 매칭
    - AI/ML 없음
    - 사용자 선호도 학습 없음
  - ❌ 실시간 가격 미반영
    - 추천 견적에 실제 중고 시장 가격 정보 없음
    - 예산 초과 여부 확인 불가

  3️⃣ 호환성 체크 부족

  - ⚠️ 기본적인 호환성만 체크
    - Socket, Memory Type만 확인
    - TDP/전력 계산 부족
    - 케이스 크기 vs 메인보드/GPU 크기 미확인
    - CPU 쿨러 높이 vs 케이스 클리어런스 미확인
  - ❌ 파워 용량 추천이 부정확함
    - 단순히 GPU TDP만 참고
    - CPU + GPU + 기타 부품 총 소비전력 계산 없음

  4️⃣ 결과 화면 개선점

  - ❌ 추천 이유 설명 부족
    - 왜 이 부품을 추천했는지 설명 없음
  - ❌ 대안 견적 제시 없음
    - 한 개 견적만 제공
    - 더 저렴한 옵션, 더 좋은 옵션 비교 불가
  - ❌ 총 예상 가격 표시 없음
    - 추천 부품의 중고 시장 가격 합계 표시 안됨
    - 사용자 예산과 비교 불가

  5️⃣ PC 조립 화면 문제

  - ❌ 여러 부품 동시 구매 불가
    - CheckoutScreen에 첫 번째 부품만 전달
    - 전체 구성을 한번에 구매하는 기능 없음
  - ❌ 예산 초과 경고 없음
    - 선택한 부품 총액이 예산을 초과해도 알림 없음
  - ❌ 부품별 대체품 제안 없음
    - "비슷한 부품 찾기" 기능 없음
    - 재고 없을 때 대안 제시 없음

  6️⃣ 데이터 관리 문제

  - ❌ 견적 샘플이 로컬 JSON
    - Firestore에서 관리하지 않음
    - Admin이 견적 추가/수정 불가
    - 앱 배포 시마다 JSON 번들 필요

  💡 개선 우선순위 제안

  🔥 긴급 (Critical)

  1. PC 조립 화면 - 여러 부품 동시 구매
  2. 총 예상 가격 표시 및 예산 초과 경고
  3. 게임 선택 UI 개선 (번호 → 검색 가능한 리스트)

  ⚡ 중요 (High)

  4. 전력 계산 개선 (PSU 용량 추천 정확도 향상)
  5. 대안 견적 제시 (3개 옵션: 저가형/중급형/고급형)
  6. 추천 이유 설명 추가

  📈 중간 (Medium)

  7. Firestore 기반 견적 관리 (Admin이 견적 CRUD 가능)
  8. 호환성 체크 강화 (TDP, 케이스 크기 등)
  9. 답변 수정 UI 개선 (질문 네비게이션)

  🌟 장기 (Low)

  10. AI 추천 알고리즘 (사용자 패턴 학습)
  11. 실시간 가격 연동
  12. 사용자 리뷰 기반 추천
