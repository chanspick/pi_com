# 📱 앱 아이콘 이미지 가이드

## 📁 이 폴더에 넣을 파일

### 1. 앱 아이콘 (필수)
**파일명:** `app_icon.png`
**규격:**
- 크기: 1024 x 1024 픽셀 (정사각형)
- 형식: PNG (투명 배경 가능)
- 해상도: 72 DPI 이상
- 용량: 1MB 이하 권장

**디자인 가이드:**
- ✅ 단순하고 명확한 디자인
- ✅ 폰에서 작게 보여도 인식 가능해야 함
- ✅ 브랜드 컬러 사용
- ❌ 너무 복잡한 디테일은 피하기
- ❌ 텍스트는 최소화 (읽기 어려움)

---

### 2. Adaptive 아이콘 (선택사항 - 권장)

**파일명:** `app_icon_foreground.png`
**용도:** Android adaptive icon의 전경 이미지
**규격:**
- 크기: 1024 x 1024 픽셀
- 형식: PNG (투명 배경)
- 안전 영역: 중앙 432 x 432 픽셀 안에 중요한 요소 배치

**설명:**
- Android 8.0(API 26) 이상에서 사용
- 다양한 모양으로 마스킹됨 (원형, 둥근 사각형 등)
- 배경색은 설정 파일에서 지정 (흰색 또는 브랜드 컬러)

---

## 🎨 디자인 예시

### 좋은 예
- 단순한 로고 (PC 부품, 컴퓨터 관련 심볼)
- 브랜드 컬러 사용
- 명확한 윤곽선

### 나쁜 예
- 복잡한 그래픽 (작게 보면 알아보기 힘듦)
- 긴 텍스트 (읽기 어려움)
- 너무 밝거나 어두운 색 (가독성 떨어짐)
